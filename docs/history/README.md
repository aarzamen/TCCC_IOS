# History

Working notes from the agent-assisted sprints of 2026, kept for provenance.
They describe decisions and evidence as of their dates and are not current
documentation; `README.md`, `ARCHITECTURE.md`, `docs/SCOPE.md` and `CLAUDE.md`
at the repository root are. Each file was moved here from the root (or from
`docs/`) on 2026-11-05 without changes.

| `DRIVING_NOTES.md` | Operator notes dictated while driving; raw task capture. |
| `RECON_NOTES.md` | Repository reconnaissance before the Granite Speech sprint. |
| `PRIOR_AUDIO_PATTERNS.md` | Survey of audio-capture patterns in the owner's other local projects. |
| `SPRINT_1_ACCEPTANCE.md` | Acceptance walk of the Granite Speech foundation sprint (2026-05-10). |

| `RESEARCH_PARAKEET.md`, `RESEARCH_GRANITE_SPEECH.md` | Alternative speech backends (both leave in v1.0, see `docs/SCOPE.md`). |
| `RESEARCH_LLM_SMALL.md`, `RESEARCH_LLAMA32B.md` | Small on-device language models and why Llama 3.2 was excluded (alternative LLM backends leave in v1.0). |
| `RESEARCH_RAM_API.md` | Memory-headroom probing on iOS. |
